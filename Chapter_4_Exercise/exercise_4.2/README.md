# 4.2 List Files Recursively

Write listNestedFiles(), a callback-style function that takes, as the
input, the path to a directory in the local filesystem and that asynchronously iterates over
all the subdirectories to eventually return a list of all the files discovered. Here is what the
signature of the function should look like:

```js
function listNestedFiles(dir, cb) {
  /* ... */
}
```

Bonus points if you manage to avoid callback hell. Feel free to create additional helper functions if needed.

## Run

To run the exercise launch:

```bash
npm run 4.2
```
